# Involvement popup images

Place one image for each image-based popup in this folder using these filenames:

- `national-badminton.png`
- `irvington-frame.png`
- `cs-kickstart.png`
- `vikinghacks.png`
- `school-badminton.png`
- `summer-programs.png`
- `hollywood.png`

The SF Bubble and piano popups are intentionally text-only until images are available.

The image paths, descriptions, alt text, and crop positions are configured in
`src/pages/involvements.astro`.
